# instacar

Análisis de datos de Instacart con pandas y JupyterLab.

## Estructura

- `data/`: tablas de Instacart (los CSV no se versionan)
- `notebooks/`: cuadernos de análisis

## Entorno (Windows, cmd)

```bat
python -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
```

## Abrir JupyterLab

```bat
jupyter lab
```
